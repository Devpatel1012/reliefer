# 🚀 Reliefer Production Deployment Guide

This guide provides step-by-step instructions for deploying **Reliefer** to production environments such as **Railway**, **Render**, **Fly.io**, or custom **Docker Compose** servers.

---

## 📋 Prerequisites & Secret Generation

Before deploying to any cloud host, generate secure production secrets using the built-in generator script:

```bash
python3 scripts/generate_prod_secrets.py
```

This will output:
1. `JWT_SECRET_KEY` (64-character crypto-random token)
2. `ENCRYPTION_KEY` (Fernet symmetric key for API token encryption at rest)

---

## 🛠️ Deployment Option 1: Railway (Recommended)

Railway automatically builds and deploys from your GitHub repository using the included `Dockerfile` and `railway.json`.

### Steps:
1. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "Deploy Reliefer to production"
   git push origin main
   ```
2. Open [Railway Dashboard](https://railway.app) and click **New Project** -> **Deploy from GitHub repo**.
3. Select your repository.
4. Add a **PostgreSQL** database service to your project.
5. In your web service settings under **Variables**, set:
   - `DATABASE_URL`: `${{ Postgres.DATABASE_URL }}`
   - `JWT_SECRET_KEY`: `<Your generated 64-char key>`
   - `ENCRYPTION_KEY`: `<Your generated Fernet key>`
   - `ALLOWED_ORIGINS`: `https://your-domain.up.railway.app`
   - `LOG_LEVEL`: `INFO`
   - `LOG_FORMAT`: `json`
6. Railway will build the Docker container and start serving at your Railway domain with HTTPS enabled automatically!

---

## 🛠️ Deployment Option 2: Render

Render deploys using the included `render.yaml` Blueprint.

### Steps:
1. Push code to GitHub.
2. Go to [Render Dashboard](https://dashboard.render.com) and click **New +** -> **Blueprint**.
3. Connect your repository. Render will automatically detect `render.yaml`.
4. Provide environment variable values (`ENCRYPTION_KEY`, `ALLOWED_ORIGINS`).
5. Click **Apply**. Render will provision PostgreSQL and your FastAPI web service.

---

## 🛠️ Deployment Option 3: Self-Hosted Docker Compose

To deploy on a VPS (DigitalOcean, AWS EC2, Hetzner, Linode) using Docker Compose:

1. Clone repository to server:
   ```bash
   git clone <your-repo-url> /opt/reliefer
   cd /opt/reliefer
   ```
2. Create `.env` file:
   ```bash
   cp backend/.env.example backend/.env
   ```
3. Edit `backend/.env` with production secrets generated by `scripts/generate_prod_secrets.py`.
4. Start multi-container stack:
   ```bash
   docker-compose up -d --build
   ```
5. Check health:
   ```bash
   curl http://localhost:8000/health
   ```

## 🔍 Pre-Flight Verification Audit

Run the automated production auditor script prior to going live:

```bash
python3 scripts/verify_prod_env.py
```

If all checks pass, your platform is 100% production-ready! 🎉
